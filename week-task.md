UDP request / response
Отправить DNS-запрос по UDP и получить response.

* - UDP socket;
* - destination address;
* - destination port;
* - timeout;
* - packet loss;
* - network error.


Практика

* 1. Написать unit-тесты на query builder. (optional)
* 2. Отправить DNS query на DNS server.
* 3. Получить raw response.
